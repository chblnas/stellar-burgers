# Stellar Burgers 🍔

Современное веб-приложение для сборки бургеров и оформления заказов. Проект разработан с нуля с использованием современного стека технологий, поддерживает масштабируемую архитектуру и высокое покрытие тестами.

## ✨ Основной функционал

- Авторизация и регистрация пользователей
- Конструктор бургеров
- Управление заказами и личным кабинетом

## 🧱 Архитектура и стек

- **Frontend:** React, TypeScript
- **Состояние:** Redux Toolkit (глобальное состояние и слайсы)
- **Маршрутизация:** React Router
- **Сборка:** Webpack
- **Стили:** CSS Modules  
- **Тестирование:** Jest + React Testing Library + Cypress

## 🧪 Тестирование

- Покрытие unit-тестами ключевых редьюсеров, утилит и компонентов  
- Интеграционные тесты конструктора бургеров

## 🚀 Запуск проекта

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка для продакшена
npm run build

# Запуск тестов
npm run test
```

## 📁 Структура проекта

```
stellar-burgers/
├─ __tests__/          # unit-тесты
├─ cypress/            # интеграционные тесты
└─ src/
   ├─ components/      # бизнес-логика и компоненты
   │  ├─ app/          # инициализация приложения
   │  └─ ui/           # UI-компоненты
   ├─ hooks/           # кастомные хуки
   ├─ pages/           # страницы
   ├─ services/        # store и слайсы
   ├─ stories/         # Storybook: примеры использования и визуальная документация компонентов
   └─ utils/           # API и утилиты
```
